# HIEROPHANT Project: campaign pages

Pages in this repo appear on the Project site under **Campaigns**. The site
picks up changes within an hour.

## After each campaign

1. **Write the log.** Open `templates/Campaign Log Template.md`, copy its text, then go
   back to the repo's front page and choose **Add file → Create new file**. Name the file
   `YYYY-MM-DD - Campaign name.md`, for example `2026-11-21 - The Lighthouse Riots.md`,
   paste the template, fill it in and click **Commit changes**.
2. **Update the running record.** Open `Campaign History.md`, click the pencil
   icon, add the campaign to it and click **Commit changes**.

## Rules

- Only `.md` files at the top level of this repo are published. Files in
  `templates/` and this README are not.
- Images go in `images/`. Put one in a page with `![[image name.png]]`.
- Start every log's file name with the date, so the newest campaign is listed first.
- This repo is public. Don't put anything private in it.
